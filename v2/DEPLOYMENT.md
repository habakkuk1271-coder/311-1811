# V2 部署一致性清單

V2 的唯一資料來源是 Google Sheet，公開讀取與管理寫入都經由同一個 Apps Script `/exec`。

每次 V2 修改後依序確認：

1. `backend/Code.gs` 儲存到 Apps Script，執行 `doGet` 確認成功。
2. 建立新版本並更新現有 Web App 部署；網址不可更換。
3. `v2/config.js` 的 API URL 仍指向同一個 `/exec`。
4. 公開頁與管理頁重新讀取，確認公告、操練、活動及歷史資料一致。
5. 預覽站完成部署後，再進行手機寬度與瀏覽器錯誤檢查。
6. 未完成上述檢查前，不合併 `main`。

管理頁的「檢查封存流程（不寫入）」可驗證封存、重試去重與歷史媒體更新規則，不會新增或修改試算表資料。
